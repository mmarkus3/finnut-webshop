## Why

Users should be able to discover and open the brand's social media channels directly from the page footer. A dedicated centered row for social links improves visibility and keeps the footer organized.

## What Changes

- Add social media links to the page footer area.
- Place social media links on their own row, centered horizontally.
- Include Instagram and Facebook links using the provided URLs.
- Keep link styling and accessibility consistent with current footer link behavior.

## Capabilities

### New Capabilities
- None.

### Modified Capabilities
- `information-page-global-footer-link`: Extend footer requirements to include a centered social-media links row with Instagram and Facebook links.

## Impact

- Affected UI: footer link component/layout in page flow.
- Affected i18n: social link labels and accessibility labels.
- Affected tests: footer rendering and link behavior assertions.
